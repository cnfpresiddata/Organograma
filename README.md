# Organograma CONFEA: página de acesso

Página publicada em https://cnfpresiddata.github.io/Organograma/

Este repositório guarda só a página de login. Ele não tem dado nenhum. Depois do login, a página baixa do Supabase do CONFEA (bucket privado `organograma`) a última versão publicada pela rotina diária das 06h. Só usuário com papel no schema `organograma` consegue ler o arquivo.

Código, rotina e documentação: repositório privado `cnfpresiddata/organograma-confea`.
